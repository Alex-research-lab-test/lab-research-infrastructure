# 实验记录

## 可复现输入

| 字段 | 内容 |
| --- | --- |
| 实验标识/任务 | 本地标识及关联任务 |
| 目标/假设 | 具体预测或待验证行为 |
| 代码 | 完整 commit；有未提交改动则单独记录补丁标识 |
| 环境 | 依赖锁定/环境文件版本、Python、CUDA、硬件型号 |
| 数据 | 版本、split 标识、许可/访问限制及已有 checksum |
| 配置 | 配置文件版本与所有 CLI overrides |
| 随机性 | seeds、重复次数、确定性相关设置 |
| 执行许可 | 数据/GPU/硬件是否已授权、资源预算 |

## 实际执行

记录准确命令、开始/结束时间及时区、退出码、产物位置。
未运行时保持“未运行”；不要写虚构的命令输出或 metrics。
公开记录不包含敏感绝对路径、原始受限数据或凭据。

## 结果与限制

记录指标定义、各次运行结果、聚合方式、不确定度、失败运行和异常处理。
对比 baseline 时明确是否使用相同数据划分与评价协议。

## 解释与后续

说明哪些观察支持或反驳假设、哪些仍需验证，以及下一项必要实验。
