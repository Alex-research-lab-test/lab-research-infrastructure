# 论文到实现的依据映射

这是空白记录模板，没有已核实的论文或复现结论。
填写时引用原始来源，不根据标题、二手摘要或模型记忆补出公式和实验结果。

## 来源

| 字段 | 内容 |
| --- | --- |
| 论文 | 标题、DOI/arXiv、版本与日期 |
| 已读取材料 | 实际读到的章节/附录/补充信息；缺失材料明确列出 |
| 官方代码 | repository、完整 commit、许可 |
| 本地基线 | repository 和完整 commit |
| 复现目标 | 指定表格/图/指标或可测试行为 |

## 对应关系

| 原文章节/公式/官方路径 | 方法含义 | 本地文件与符号 | 适配或差异及理由 | 验证证据 |
| --- | --- | --- | --- | --- |
| 填写确切来源锚点 | 记录实际语义 | 给出路径、符号和版本 | 无差异也应明确 | 实际检查或“未验证” |

## 实验协议

记录观测/动作语义、输入维度、归一化、数据版本/划分、训练配置、种子、
评价协议、baseline 与误差统计。缺失值保持未验证，不用习惯默认值代替。

## 结论边界

区分忠实复现、工程适配和方法创新；列出当前证据支持的结论以及不支持的结论。
