# 研究任务记录

状态：计划，尚未执行。将下列字段替换为本任务的真实内容后提交。

| 字段 | 内容 |
| --- | --- |
| 任务/Issue | 记录 Issue URL 或本地任务标识 |
| 研究问题 | 写明要回答的问题或建立的能力 |
| 目标结果 | 可观测结果与成功/失败判据 |
| 主要依据 | 论文标识与版本、官方实现 commit 或需求来源 |
| 代码基线 | 实际 repository 和 commit |
| 范围 | 将修改的组件及明确排除的算法/实验 |
| 输入材料 | 可访问的源码、数据版本和说明 |
| 资源预算 | CPU/GPU 时间、数据访问、硬件许可；未授权则不运行 |
| 验证计划 | 各层检查命令、所需输入、预期可验证条件 |
| 产物 | 文件/报告位置；不在此放实际数据或权重 |
| 证据缺口 | 尚未取得的输入、权限或研究依据 |

执行后记录实际 commit、检查结果、偏离计划的原因和未完成事项。
